## ☁️ Deployment to Streamlit Cloud

This application can be deployed to Streamlit Cloud for free. Here are the steps:

1.  **Create a GitHub Repository:**
    *   Make sure this code is in a GitHub repository that you own.

2.  **Sign up for Streamlit Cloud:**
    *   Go to [share.streamlit.io](https://share.streamlit.io) and sign up using your GitHub account.

3.  **Deploy the App:**
    *   From your Streamlit Cloud workspace, click on "**New app**".
    *   Select the GitHub repository containing this code.
    *   Choose the branch (e.g., `main` or `master`).
    *   The "Main file path" should be `app.py`.
    *   Click "**Deploy!**".

Streamlit Cloud will automatically detect the `requirements.txt` file and install all the necessary dependencies. Your application will be live in a few minutes.
